# lolpin 改进版

lolPing AI 第二版 · 0.5.2。仓库名：`lolpin-improved`。

[下载 Windows 安装包与源码包](https://github.com/etasp/lolpin-improved/releases/tag/v0.5.2)

基于 [darrenprx/lolPing](https://github.com/darrenprx/lolPing) 的自用改造，原作者 Danrui Meng。本包不是原作官方更新。

## 两种模式

- **娱乐 ping**：只显示信号和联机互动，不读取剪贴板、不截图、不调用 AI。
- **AI 模式**：本机实际发出的 ping 可执行各自的动作。**Ctrl＋Alt＋A** 切换，设置 → AI 助手 / 模式中也能切换。轮盘中心显示 PING / AI，切换时有提示。
- 新安装默认关闭 AI 模式；升级保留原来的开关状态，请按需要切换。若快捷键被其他应用占用，使用设置开关。
- 好友的信号和设置里的预览始终只展示，不会触发你的 AI。

在“每种 ping 的动作”中展开任意信号，可改为只发 ping、直接呼出 AI、打开智能面板、复制提示词或本地提醒，也可单独指定 AI、修改提示词。绿色旗帜改成“智能面板”后也能进行 API 解释。

## 两种 AI 用法

1. **呼出已有 AI**：Codex 桌面、Claude 桌面的 Code 页面（CC）、DeepSeek 网页版（DS）。直接呼出不会代你发送问题。
2. **API 直答**：设置 → AI 助手 / 模式 → API 配置。填写兼容 Chat Completions 的 API 地址、模型和密钥，点击“保存 API 配置”。默认地址 https://api.deepseek.com，默认模型 deepseek-flash；请以自己的服务商账户提供的模型为准。API 请求由你自己的账户计费。

先复制要分析的文字，再发对应信号；智能面板会显示文字，也可直接输入。点击“发送给 API”后才发送。也可以点“复制并打开 AI”，到桌面或网页 AI 中粘贴并发送。

需要看图时，点击“截取信号附近画面”，先预览再发送。可以取消勾选附图。图片需要支持视觉输入的模型；呼出外部 AI 时只复制文字，图片需自行附上。本版不会自动后台截屏，也不自动提交问题。

密钥通过 Electron safeStorage 在本机加密，保存于单独的 ai-key.enc，不写入 settings.json，不会通过房间传给好友。系统加密不可用时拒绝保存密钥；在软件中可以删除密钥。

## 联机互 ping

原作已具备房间同步；这次增加了明确的玩法说明、复制邀请和测试 ping。

1. 两个人都安装 lolPing。设置 → 联机互 ping → 创建房间。
2. 点“复制邀请与玩法”，把邀请发给朋友。
3. 朋友在同一页粘贴整段邀请，加入同一房间。
4. 按住 Alt＋鼠标左键拖动，选择信号并松开。对方看到相对位置的信号和你的名字。
5. 可以先点“发一个测试 ping”，请朋友确认屏幕中央是否出现。显示已发送不等于已收到。

最多8人。同一网络优先使用局域网；异地双方开启“允许互联网连接”，使用原作的加密公共中继。可静音房间或个人，并限制收到信号的频率。连接失败时检查网络、房间码和软件中的连接提示，不要以为点了发送就一定送达。

## 验证与限制

- 类型检查、构建和719项测试通过。
- 真实 Electron 界面已验证娱乐 / AI 模式、PING / AI 标识、截图预览、文本与图片 API 请求、邀请复制、测试 ping。
- 真实桌面应用与本机测试好友通过 UDP 双向互 ping，好友信号未触发本机 AI；独立局域网和中继测试也验证了双向收发。
- API 使用本机兼容测试服务器验证，未使用真实付费密钥请求云端。跨两台实体电脑、跨不同公网的连通性需你与朋友进一步确认。
- Codex 的桌面呼出先前已在本机验证；CC / DS 固定入口沿用上一版，未宣称本次完成各自的实际窗口实测。
- 定制版不自动升级到原作版本，避免覆盖新增功能。请使用本定制安装包更新。
