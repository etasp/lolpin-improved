# lolpin 改进版

lolPing AI 第二版 · 0.6.1。仓库名：`lolpin-improved`。

[下载 Windows 安装包与源码包](https://github.com/etasp/lolpin-improved/releases/tag/v0.6.1)

基于 [darrenprx/lolPing](https://github.com/darrenprx/lolPing) 的自用改造，原作者 Danrui Meng。本包不是原作官方更新。

## 0.6.1 呼出修复

- Codex 入口改为官方支持的 codex://threads/new。
- Windows 在打开链接后恢复并激活 Codex / ChatGPT 的桌面窗口，失败时显示提示；不会注入按键或自动发送问题。
- 真实桌面支援 ping 已验证能把 AI 窗口置于前台，娱乐模式不呼出 AI；725 项测试通过。
- 轮盘操作：按住触发键（默认 Alt），再按住鼠标左键拖动，选择后松开左键。只按 Alt 不展开轮盘。
- 如果微信等窗口里轮盘无法展开，可在“触发”中关闭“全屏程序中暂停”；该选项关闭后，游戏等全屏程序也不会自动暂停 ping，请按自己的使用场景设置。
- 要用问号直接呼出 AI，在“AI 助手 / 模式 → 每种 ping 的动作”中将问号改成“直接呼出 AI”。API 智能面板仍可选择使用。

## 0.6.1 屏幕 AI 气泡

结合 [LOLping AI Assistant](https://github.com/renyuzhu1-jpg/LOLping-AI-Assistant) 的屏幕气泡交互，保留 Codex / CC / DS 呼出和手动确认面板。

- 在设置 → AI 助手中保存自己的 API 地址、模型与密钥，再在“屏幕答案气泡”中启用预设，或逐个信号选择“API 气泡直答”。
- 绿色旗帜解释，问号解惑，敌方视野翻译，诱饵给聊天回复建议；提示词可自行修改，其他信号也能单独配置。
- 选择“信号附近屏幕”会截取信号附近约 1000×700 区域并自动发送给你配置的 API，需支持图像输入的模型。选择“已复制文字”则发送剪贴板文字。
- 悬停保留气泡，可选中文字或点击复制；停留时间可设 5–300 秒。答案以纯文本显示。
- 没配置密钥时只提示配置，不读取上下文。娱乐模式、好友信号和设置预览不读取上下文，也不调用 AI。
- 修复部分环境中设置无法保存的 EXDEV 问题，写入前保留原设置备份；加强轮盘和气泡的窗口层级。
- 微信窗口上的轮盘和 Codex 前台激活已由使用者确认。升级保留既有逐个信号的动作；配置 API 后可自行启用气泡直答。
- 类型检查、构建及 725 项测试通过；隔离桌面实例验证了图片请求、翻译/回复提示词、复制、屏幕边缘定位和娱乐模式。测试使用虚构图文及本地 API，未调用付费云端接口。

来源固定提交：a58aefe4f972415236ce4b26ce268328f2f4ea4a。气泡 renderer 的改编说明见 THIRD_PARTY_NOTICES.md，保留 MIT 许可与署名。

## 两种模式

- **娱乐 ping**：只显示信号和联机互动，不读取剪贴板、不截图、不调用 AI。
- **AI 模式**：本机实际发出的 ping 可执行各自的动作。**Ctrl＋Alt＋A** 切换，设置 → AI 助手 / 模式中也能切换。轮盘中心显示 PING / AI，切换时有提示。
- 新安装默认关闭 AI 模式；升级保留原来的开关状态，请按需要切换。若快捷键被其他应用占用，使用设置开关。
- 好友的信号和设置里的预览始终只展示，不会触发你的 AI。

| 信号 | 用途 | 默认动作 |
|---|---|---|
| 绿色旗帜 / 请求协助 | 求助 | 直接呼出默认 AI |
| 问号 / 敌人消失 | 提问、解惑 | 打开智能面板 |
| 红色危险 | 找坑点、风险检查 | 打开智能面板 |
| 推进 | 下一步 | 打开智能面板 |
| 正在赶来 | 开始行动 | 本地提醒 |
| 全力进攻 | 辅导、确认方案 | 打开智能面板 |
| 需要视野 | 补背景 | 打开智能面板 |
| 敌方视野 | 翻译 | 打开智能面板 |
| 普通信号 | 标记 | 只发 ping |
| 诱饵 | 聊天回复 | 打开智能面板 |

在“每种 ping 的动作”中展开任意信号，可改为只发 ping、直接呼出 AI、打开智能面板、复制提示词或本地提醒，也可单独指定 AI、修改提示词。绿色旗帜改成“智能面板”后也能进行 API 解释。

## 两种 AI 用法

1. **呼出已有 AI**：Codex 桌面、Claude 桌面的 Code 页面（CC）、DeepSeek 网页版（DS）。直接呼出不会代你发送问题。
2. **API 直答**：设置 → AI 助手 / 模式 → API 配置。填写兼容 Chat Completions 的 API 地址、模型和密钥，点击“保存 API 配置”。默认地址 https://api.deepseek.com，默认模型 deepseek-flash；请以自己的服务商账户提供的模型为准。API 请求由你自己的账户计费。

先复制要分析的文字，再发对应信号；智能面板会显示文字，也可直接输入。点击“发送给 API”后才发送。也可以点“复制并打开 AI”，到桌面或网页 AI 中粘贴并发送。

需要看图时，点击“截取信号附近画面”，先预览再发送。可以取消勾选附图。图片需要支持视觉输入的模型；呼出外部 AI 时只复制文字，图片需自行附上。手动确认面板不会自动发送；只有明确设为 API 气泡直答的信号会读取指定来源并请求 API。

密钥通过 Electron safeStorage 在本机加密，保存于单独的 ai-key.enc，不写入 settings.json，不会通过房间传给好友。系统加密不可用时拒绝保存密钥；在软件中可以删除密钥。

## 联机互 ping

原作已具备房间同步；这次增加了明确的玩法说明、复制邀请和测试 ping。

1. 两个人都安装 lolPing。设置 → 联机互 ping → 创建房间。
2. 点“复制邀请与玩法”，把邀请发给朋友。
3. 朋友在同一页粘贴整段邀请，加入同一房间。
4. 按住 Alt＋鼠标左键拖动，选择信号并松开。对方看到相对位置的信号和你的名字。
5. 可以先点“发一个测试 ping”，请朋友确认屏幕中央是否出现。显示已发送不等于已收到。

最多8人。同一网络优先使用局域网；异地双方开启“允许互联网连接”，使用原作的加密公共中继。可静音房间或个人，并限制收到信号的频率。连接失败时检查网络、房间码和软件中的连接提示，不要以为点了发送就一定送达。

## 验证与限制

- 类型检查、构建和725项测试通过。
- 真实 Electron 界面已验证娱乐 / AI 模式、PING / AI 标识、截图预览、文本与图片 API 请求、邀请复制、测试 ping。
